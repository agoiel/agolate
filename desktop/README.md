# Manhwa Translator — версия 0.1 (ПК, Windows)

Переводчик манхвы, манги и маньхуа прямо с экрана. Выделяете область чтения,
программа находит облака, собирает из них текст и переводит.

## Установка

1. Установите **Python 3.10 или новее** с https://www.python.org/downloads/
   При установке отметьте галочку **«Add python.exe to PATH»**.
2. Распакуйте папку `manhwa_translator` куда удобно.
3. Запустите **`run.bat`**. В первый раз он сам создаст окружение и скачает библиотеки
   (пара минут). Дальше программа будет открываться сразу.

Если окно не появилось — запустите `run_debug.bat`, там будет видна ошибка.

### Сборка в exe

1. Один раз запустите `run.bat` (он установит библиотеки), потом закройте программу.
2. Запустите **`build.bat`**.
3. Готовая программа появится в папке `dist\ManhwaTranslator\`. Запускайте
   `ManhwaTranslator.exe`. Python для неё больше не нужен, папку можно переносить
   и копировать на другие компьютеры целиком.

Настройки (`config.json`) и глоссарии лежат рядом с exe. EasyOCR в exe не входит
(он весит 1–2 ГБ), используется Windows OCR.

Иногда антивирус ругается на только что собранные exe — это ложная тревога,
типичная для программ, собранных PyInstaller. Добавьте папку в исключения.

### Распознавание текста (Windows OCR)

Программа использует встроенный в Windows 10/11 OCR — быстрый и бесплатный.
Для корейского (и других языков) нужен языковой компонент OCR.

**Ставить вручную ничего не нужно.** Если компонента нет, программа при запуске сама
предложит его докачать: нажмите «Установить», Windows один раз спросит разрешение
администратора, откроется окно установки, после чего программа перезапустится.
Дальше права администратора не нужны. Можно сразу выбрать «Установить все языки».

Если автоматическая установка не сработала (например, отключён Центр обновления):
Параметры Windows → Время и язык → Язык и регион → Добавить язык → нужный язык.
Или в PowerShell от имени администратора:

```
Add-WindowsCapability -Online -Name "Language.OCR~~~ko-KR~0.0.1.0"   # корейский
Add-WindowsCapability -Online -Name "Language.OCR~~~ja-JP~0.0.1.0"   # японский
Add-WindowsCapability -Online -Name "Language.OCR~~~zh-CN~0.0.1.0"   # китайский
```

## Как пользоваться

| Клавиши | Действие |
|---|---|
| **Alt+Q** | выделить область чтения (тянете прямоугольник мышкой, Esc — отмена) |
| **Alt+W** | перевести то, что сейчас в области |
| **Alt+E** | показать / скрыть перевод |
| **Alt+R** | режим «Авто»: листаете главу, перевод появляется сам, когда страница остановилась |

Клавиши меняются в настройках. Область запоминается между запусками.

- **«Новый тайтл»** — сбросить контекст и кэш, когда переходите к другой манхве.
- **«Из файла…»** — перевести сохранённую картинку (удобно для проверки).

Перевод можно показывать **поверх облаков** или в **отдельном окне списком** (или и так, и так) —
переключается в настройках.

## Переводчики

Выбираются в «Настройки → Перевод».

| Переводчик | Ключ | Стоимость | Качество |
|---|---|---|---|
| **Google (без ключа)** | не нужен | бесплатно | среднее. Неофициальный способ, Google может его ограничить |
| **DeepL** | https://www.deepl.com/pro-api (план Free) | 500 тыс. символов/мес. бесплатно | хорошее, учитывает контекст |
| **Microsoft** | портал Azure → ресурс Translator, уровень F0 | 2 млн символов/мес. бесплатно | среднее |
| **Gemini** | https://aistudio.google.com → Get API key | есть бесплатный лимит, дальше копейки | лучшее: понимает контекст, тон, пол персонажей |
| **OpenAI-совместимый** | зависит от сервиса | — | для OpenAI, OpenRouter, DeepSeek или **локальной модели** |

Одна глава — это примерно 2–4 тысячи символов текста.

**Локальная модель (бесплатно, без интернета):** установите [Ollama](https://ollama.com),
выполните `ollama pull qwen2.5:7b`, выберите переводчик «OpenAI-совместимый» с адресом
`http://localhost:11434/v1` и моделью `qwen2.5:7b`. Нужна видеокарта с 8+ ГБ памяти.

### Почему не тратится лишнее

- **Кэш:** уже переведённые облака запоминаются. При прокрутке те же облака не
  отправляются повторно.
- **Контекст фиксированного размера:** переводчику передаются только последние
  12 реплик (настраивается), а не вся история. 1-я и 300-я глава стоят одинаково.

## Глоссарий тайтла

Имена, термины, звания, обращения — чтобы герой не назывался в каждой главе по-разному.

«Настройки → Перевод → Глоссарий тайтла → Новый…». Заполняете таблицу:
оригинал, перевод, заметка (например, «главный герой, мужчина»).

- Обычные переводчики (Google, DeepL, Microsoft): термин подменяется на ваш перевод
  ещё до отправки («якорь»), переводчик оставляет его как есть.
- ИИ-переводчики (Gemini и др.): получают термины с заметками и сами склоняют их по падежам.

Глоссарии лежат в папке `glossaries` в формате JSON — этот же формат будет и в Android-версии.

## Если что-то распознаётся плохо

«Настройки → Распознавание»:

- **Текст не находится или с ошибками** → увеличьте «Увеличение перед OCR» (2.0–2.5).
- **Одно облако распалось на части** → увеличьте «Зазор между строками».
- **Соседние облака склеились** → уменьшите «Зазор между строками».
- **Мешают переводы звуков** → включите «Не переводить текст поверх рисунка».

Для подробной проверки можно запустить из командной строки:

```
.venv\Scripts\python main.py --image страница.png --debug отладка.png
```

В `отладка.png` будут нарисованы найденные строки (оранжевые) и облака
(зелёные — обычные, синие — плашки, розовые — текст поверх рисунка).

### Запасной движок OCR

Если Windows OCR не подходит, можно поставить EasyOCR (тяжёлый, ~1–2 ГБ):

```
.venv\Scripts\python -m pip install easyocr
```

и выбрать его в настройках.

## Как это устроено

```
app/
  capture.py        снимок выделенной области
  ocr/              распознавание: Windows OCR, EasyOCR
  bubbles.py        склейка строк в облака, тип фона, порядок чтения (без нейросети)
  glossary.py       глоссарий и якоря
  translators/      Google, DeepL, Microsoft, Gemini, OpenAI-совместимый
  pipeline.py       весь конвейер + кэш и контекст сессии
  ui/               окна: панель, выделение, перевод поверх облаков, список, настройки
```

Логика в `bubbles.py`, `glossary.py` и `translators/` не зависит от интерфейса —
её же перенесём в Android-версию.

Ключи API хранятся в `config.json` рядом с программой в открытом виде — не выкладывайте
этот файл в интернет.
