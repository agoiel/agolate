# Manhwa Translator

Переводчик манхвы, манги и маньхуа прямо с экрана: выделяете область, программа
находит облака, собирает текст и переводит.

- **`desktop/`** — версия для ПК (Windows, Python). Инструкция в `desktop/README.md`.
- **`android/`** — версия для Android (Kotlin). Инструкция ниже.

## Android

### Как получить APK

APK собирается автоматически на GitHub при каждом изменении в папке `android/`:

1. Откройте вкладку **Actions** в репозитории.
2. Выберите последний запуск **Android APK** с зелёной галочкой.
3. Внизу, в разделе **Artifacts**, скачайте `ManhwaTranslator-apk`. Это zip, внутри
   `ManhwaTranslator.apk`.
4. Перекиньте APK на телефон и установите. Android попросит разрешить установку
   из этого источника.

Новые версии ставятся поверх старых без удаления: все сборки подписаны одним ключом.

### Как пользоваться

1. Откройте приложение, выберите язык и переводчик.
2. Нажмите **«Запустить плавающую кнопку»**. В первый раз Android попросит:
   - разрешить **показ поверх других приложений**;
   - разрешить **уведомления** (в них кнопка «Остановить»);
   - разрешить **запись экрана**. Выберите **весь экран**.
3. Откройте читалку. Появится круглая кнопка **«Аа»**:
   - **нажатие** — перевести область (в первый раз попросит её выделить);
   - **ещё нажатие** — убрать перевод;
   - **долгое нажатие** — выделить область заново;
   - кнопку можно **перетаскивать**.

Разрешение на запись экрана Android спрашивает при каждом запуске переводчика.
Это ограничение системы. На Android 15+ запись также останавливается при блокировке
экрана, тогда переводчик нужно запустить снова.

**Проверить без читалки:** кнопка «Проверить на картинке» или скриншот →
«Поделиться» → Manhwa Translator.

### Распознавание

Используется Google ML Kit через сервисы Google Play. Модели для корейского,
японского и китайского скачиваются сами (нужен интернет при первом использовании),
поэтому APK лёгкий. На телефонах без сервисов Google (новые Huawei/Honor)
распознавание работать не будет.

### Переводчики и глоссарий

Те же, что в ПК-версии: Google без ключа, DeepL, Microsoft, Gemini,
OpenAI-совместимые. Глоссарий редактируется в приложении строками
`оригинал = перевод | заметка`. Формат файлов тот же, что на ПК.
